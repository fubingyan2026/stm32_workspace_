# 机器人电机电源预充电系统 详细需求与实施计划

## 1. 概述与设计目标
- **背景**：电机驱动板后级具备大容性负载，直接上电会产生极大的瞬间浪涌电流（Inrush Current），容易导致上级母线跌落、器件打火或损坏。
- **目标**：通过 Buck 拓扑半桥电路，采用“**低频微脉冲 $\to$ 脉宽爬升 $\to$ 频率爬升 $\to$ 占空比主升**”的四阶段平滑软启动策略，将浪涌电流限制在安全阈值内，平稳建立后级母线电压。

---

## 2. 硬件接口与信号定义

| 信号/变量名 | 类型 | 方向 | 电平/类型 | 逻辑与说明 |
| :--- | :--- | :--- | :--- | :--- |
| `DRV_PWM_CH_MOTOR_CHG_IN` | 定时器 PWM | 输出 | 3.3V 推挽/高精定时器 | Buck 半桥驱动 PWM 控制引脚 |
| `MOTOR_POWER_CHG_EN` | GPIO | 输出 | 高电平有效 (3.3V) | 半桥驱动使能引脚；**拉低可复位 OCP 锁存** |
| `MOTOR_POWER_CHG_OCP_FLAG` | GPIO / 中断 | 输入 | 高电平有效 (3.3V) | 硬件过流标志位（高 = 过流，硬件自动锁存） |
| `motor_power_mv` | ADC 采集 | 全局变量 | `uint32_t` (mV) | Buck 末端输出实时电压 |

> **注**：初始 $T_{on} \approx 5.95\text{ ns}$ 对单片机主频/HRTIM（高分辨率定时器）有极高要求（如 168MHz 时钟周期正好为 $5.95\text{ ns}$，HRTIM 分辨率可达皮秒级）。若 MCU 普通定时器无法输出 < 10ns 脉宽，需在底层做脉冲舍入或基于 HRTIM 驱动。

## 3. 软启动四阶段时序与控制逻辑

软启动总耗时基准设为 **500 ms**，控制周期推荐为 **$1\text{ ms}$ / 次**。

```
[0ms]        [25ms]             [50ms]                                    [500ms]
  |  阶段二    |      阶段三       |                  阶段四                   | 稳态
  | 50kHz 恒频 | Ton=167ns 恒定    | 600kHz 恒频                              | 600kHz 90%
  | Ton爬升    | 50k->600kHz升频   | Duty 10% -> 90% 爬升                     | 直通/稳态运行
```

### 3.1 阶段详细规格

#### 【阶段一：初始状态】(0 ms)
- **触发条件**：收到上电预充电指令。
- **动作**：
  1. 确保 `MOTOR_POWER_CHG_EN` 先拉低 $5\text{ ms}$，清除可能存在的历史 OCP 状态。
  2. 配置 PWM 初始参数：$f = 50\text{ kHz}$ ($T_{period} = 20\,\mu\text{s}$)，$T_{on} = 5.95\text{ ns}$（占空比 $\approx 0.0297\%$ 或定时器最低可输出有效细分）。
  3. 拉高 `MOTOR_POWER_CHG_EN`，启动 PWM 输出，计时器清零并开始走时。

#### 【阶段二：微脉宽爬升】(0 ~ 25 ms)
- **参数控制**：
  - 频率 $f$：恒定 $50\text{ kHz}$ ($T_{period} = 20000\text{ ns}$)
  - 脉宽 $T_{on}(t)$：从 $5.95\text{ ns}$ 线性增加至 $167\text{ ns}$
  - 公式：$T_{on}(t) = 5.95 + \left(\frac{167 - 5.95}{25}\right) \times t \quad (t \in [0, 25]\text{ ms})$
  - 占空比 $Duty(t) = \frac{T_{on}(t)}{20000\text{ ns}} \times 100\%$（最终达到 $\approx 0.835\%$）

#### 【阶段三：变频阶段】(25 ~ 50 ms)
- **参数控制**：
  - 脉宽 $T_{on}$：恒定 $167\text{ ns}$
  - 频率 $f(t)$：从 $50\text{ kHz}$ 线性增加至 $600\text{ kHz}$
  - 公式：$f(t) = 50 + \left(\frac{600 - 50}{25}\right) \times (t - 25) \quad (t \in [25, 50]\text{ ms})$
  - 周期 $T_{period}(t) = \frac{10^6}{f(t)}\text{ ns}$，占空比随频率增加自然从 $0.835\%$ 升至 $10.02\%$

#### 【阶段四：主占空比爬升】(50 ~ 500 ms)
- **参数控制**：
  - 频率 $f$：恒定 $600\text{ kHz}$
  - 占空比 $Duty(t)$：从 $10\%$ 线性增加至 $90\%$
  - 公式：$Duty(t) = 10\% + \left(\frac{90\% - 10\%}{450}\right) \times (t - 50) \quad (t \in [50, 500]\text{ ms})$

#### 【最终稳态】(500 ms 之后)
- **参数控制**：保持 $f = 600\text{ kHz}$，占空比 $90\%$。
- **退出/移交**：置位 `Precharge_Done` 标志，可将电源控制权移交给主控旁路继电器/主功率回路。

## 4. 异常检测与安全保护机制

```
                     +--------------------+
                     |  IDLE / OFF 状态   |
                     +---------+----------+
                               | 启动预充电
                               v
                     +--------------------+
                     |   预充电运行状态    | <------+ (重试)
                     +---------+----------+        |
                               |                   |
            +------------------+------------------+
            | 发生 OCP / 异常超时                 | 正常完成
            v                                     v
+-----------------------+              +----------------------+
|  OCP 故障处理模式      |              |   PRECHARGE_DONE     |
| 1. EN=0, PWM Disable  |              +----------------------+
| 2. 延时 10ms 消除锁存  |
| 3. 重试计数 < 3 ? ----+
| 4. 超过重试 -> 永久锁定|
+-----------------------+
```

### 4.1 OCP（硬件过流）处理策略
1. **中断响应/轮询检测**：配置 `MOTOR_POWER_CHG_OCP_FLAG` 对应引脚为**外部中断（上升沿触发）** + 控制周期内状态校验。
2. **动作逻辑**：
   - 立即关闭 PWM 输出，将 `MOTOR_POWER_CHG_EN` 拉低。
   - 启动过流恢复状态机，延时 $10\text{ ms}$（确保硬件锁存清除）。
   - **重试机制**：
     - 单次启动最多允许重试 **3 次**。
     - 若重试次数 $< 3$：重置软启动状态机，从阶段一重新开始预充电。
     - 若重试次数 $\ge 3$：判定为后级严重短路，停机并上报 `FAULT_PRECHARGE_SHORT_CIRCUIT` 错误码。

### 4.2 电压上升斜率与超时保护
- **空载/脱焊检测**：若进入阶段四（$t = 100\text{ ms}$）时，`motor_power_mv` 仍低于 $1000\text{ mV}$，判定为未接负载或上电故障。
- **充饱提前切稳态（可选优化）**：若在 500ms 内 `motor_power_mv` 已达到设定母线电压的 $95\%$ 以上，可平滑转入稳态，无需死等 500ms。
