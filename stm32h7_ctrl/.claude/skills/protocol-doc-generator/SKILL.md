# 嵌入式通信协议文档生成规范技能包

## 1. 协议文档标准大纲

生成文档时必须严格遵循以下 7 章节加附录的树状大纲，不得擅自合并或调换顺序：

```text
1. 系统架构          — 一句话协议概述 + 通用设计原则表
2. 布局/寻址空间     — 存储/寄存器地址表 + 核心结构体字段表
3. 通信链路层        — 逻辑通道/标识符分配 + 帧协商与通用帧格式
4. 协议帧定义        — 命令字(CMD)一览表 + 逐帧详细解析
5. 升级/业务流交互    — mermaid sequenceDiagram 关键时序 + 边界与断点续传设计
6. 超时与错误处理    — 超时参数表 + 状态转移矩阵 + 错误恢复与重试表
7. 启动/初始化决策   — 初始化条件分支判断表
附录               — 传输时序图例(表格表示) + 关键宏与常量表
```

---

## 2. 强力排版与表格约束

### 2.1 帧字节偏移表 (Byte Offset Table)

- **硬性规定**：禁止使用长文本或裸十六进制串描述帧。必须使用最高 **6 列**的偏移表格表示（长帧必须分行或省略 Padding 列）：

```markdown
| Byte 0 | Byte 1 | Byte 2 | Byte 3 | ... | Byte N |
|--------|--------|--------|--------|-----|--------|
| [字段1] | [字段2] (MSB) | | | (LSB) | [字段N] |
```

### 2.2 字段说明表

紧接字节偏移表下方，结构如下：

```markdown
| 字段 | 偏移 | 长度 | 说明 |
|------|------|------|------|
| [名称] | Byte X | N | [描述]（必须写明：[类型]、[端序]、[取值范围]） |
```

### 2.3 状态转移矩阵 (用表格代替状态图)

```markdown
| 从 → 到 | STATE_A | STATE_B | STATE_C |
|---------|:---:|:---:|:---:|
| **STATE_A** | — | [触发条件] | |
| **STATE_B** | [触发条件] | — | [触发条件] |
```

### 2.4 超时与错误参数表 (统一归入第 6 章)

```markdown
| 参数/错误码 | 数值/值 | 触发条件 | 行为与恢复策略 |
|------------|---------|----------|----------------|
| [参数名] | [数值+单位] | [判定条件] | [重试/降级动作] |
```

## 3. 时序交互设计标准 (Mermaid)

- **硬性禁止**：禁止在文档内生成 `flowchart` (流程图) 和 `stateDiagram` (状态图)。这些图形逻辑一律使用上述“状态转移矩阵”表格表示。
- **唯一允许**：仅允许生成 `sequenceDiagram` (时序图)。
- **精简原则**：时序图只画出正常、高内聚的关键业务流。错误流和超时判定一律使用第 6 章的错误恢复表展示，避免时序图过于混乱。

---

## 4. 词汇与格式命名约定 [硬性校验]

| 语境 | 规则 | 示例 |
| :--- | :--- | :--- |
| **字节/数据数值** | 反引号包裹 + 16进制 `0x` 前缀（小写字母） | `` `0x01` ``, `` `0xAF` `` |
| **宏/枚举成员** | 反引号包裹 + 大写蛇形 | `` `BOOT_CMD_START` `` |
| **协议字段变量** | 反引号包裹 + 小写蛇形 | `` `fw_total_size` `` |
| **物理/逻辑地址** | 反引号包裹 + 16进制表示 | `` `0x08000000` `` |
| **基本数据类型** | 反引号包裹 + 标准 `stdint.h` 类型 | `` `uint32_t` ``, `` `uint8_t` `` |

---

## 5. 绝对禁止清单（AI 生成与评审红线）

1. ❌ **禁止** 使用裸十六进制文本或连续空格表示帧格式。
2. ❌ **禁止** 字节偏移表超出 6 列。
3. ❌ **禁止** 超时定义、错误码零散分布在各协议帧定义中，所有防御性处理必须收敛在第 6 章。
4. ❌ **禁止** 在传输图例（附录）中使用无修饰的裸代码块，必须使用表格进行行级拆解与标注。
