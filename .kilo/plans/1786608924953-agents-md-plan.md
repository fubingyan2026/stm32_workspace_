# Plan: 重构 srv_ht_torque_test.c — 两端点(0 ↔ +POS_LIMIT_DEG)往复 + 梯形加减速

## 目标

把当前「首周期直反 + ±LIMIT↔0↔∓LIMIT 三路点 + dir/first_cycle 多标志」的往复状态机，简化为只有两个端点 `0` 与 `+POS_LIMIT_DEG`（=7200°=20R）之间的简单往复。梯形加减速沿用现有位置梯形模式（`0x07 06` + `0x1F/0x20/0x21` 参数），不动电机协议侧。

## 端点与状态

- 两个端点：`0`（初始/返回点）与 `+POS_LIMIT_DEG`（正极限 20R）。
- 每电机只有两个状态，由目标值本身表示：`s_motor_target_iq[i]` 在 `+POS_LIMIT_IQ` 与 `0` 之间翻转。
- 上电扫描完成后，第一个目标直接下发 `+POS_LIMIT_IQ`（从任意位置先运动到正极限），到位后翻转到 `0`，再翻转回 `+POS_LIMIT_IQ`，如此往复。无需首周期特殊处理。

## 改动清单（service/srv_ht_torque_test.c）

1. **常量区**
   - `SRV_HT_TORQUE_TEST_POS_LIMIT_DEG`：注释由「摆动半幅」改为「正极限角度（从 0 到该角度的单侧摆幅）」，值保持 `(1800*4)`。
   - `SRV_HT_TORQUE_TEST_POS_HALF_REV_IQ` → 重命名 `SRV_HT_TORQUE_TEST_POS_LIMIT_IQ`（= `POS_LIMIT_DEG/360×2^24`，仍 20R），全文件替换引用并更新注释。
   - 删除 `SRV_HT_TORQUE_TEST_INITIAL_AT_MAX`（不再有 ± 选择）。
   - `SRV_HT_TORQUE_TEST_REACH_TIMEOUT_MS`：10000 → 60000，注释说明必须大于 20R 梯形单程时长（按 MAX_SPEED/ACCEL/DECEL 估算约 22s），仅作堵转/丢帧兜底。
2. **变量区**：删除 `s_motor_dir[]`、`s_motor_first_cycle[]`。
3. **start()**：删除对 `s_motor_dir`、`s_motor_first_cycle` 的两处 memset。
4. **scan_done()**
   - 初始目标直接设 `s_motor_target_iq[i] = SRV_HT_TORQUE_TEST_POS_LIMIT_IQ`（去掉 INITIAL_AT_MAX 三元、dir、first_cycle 赋值）。
   - 保持 `enable → set_mode → set_trapezoid → cmd_position_all` 顺序不变。
   - 日志改为「初始端点 +POS_LIMIT_DEG，两端点 0↔+LIMIT 往复」。
5. **advance_target()**：整体替换为两端点翻转（删 first_cycle 分支、删 ±LIMIT↔0 三分支）：
   ```c
   const int32_t new_target = (s_motor_target_iq[idx] >= SRV_HT_TORQUE_TEST_POS_LIMIT_IQ)
                                  ? 0 : SRV_HT_TORQUE_TEST_POS_LIMIT_IQ;
   s_motor_target_iq[idx] = new_target;
   s_motor_target_ms[idx] = now;
   /* LOG_I 打印翻转目标 */
   srv_ht_torque_test_send_position(s_motor_ids[idx], new_target);
   ```
6. **step() 到达/驻留/超时循环**：保持不变（到达 → 驻留 `REVERSAL_DWELL_MS` → `advance_target`；超时 → `advance_target`）。`reach_arrived()` 不变（阈值 3°）。
7. **保留不动**：扫描找地址、使能/设模式/设梯形参数、位置轮询(0x06)、报警(0xFF)/电压(0x87)/掉线(NORESP) 监控、30 天计时、恢复在线重发当前目标。
8. **模块头注释**（文件顶部 8-30 行）与 `srv_ht_torque_test.h` 的 start/step 注释同步改为「0 ↔ +POS_LIMIT_DEG 两端点往复 + 梯形加减速」。

## 风险 / 注意

- 20R 直接阶跃 > 文档 §8 的 6R，可能触发 `0x0200` 阶跃过大报警（若电机在梯形模式下仍按命令阶跃检查）。用户已选定此端点，需实测确认不报警；若报警，需中间加过渡点或缩小 `POS_LIMIT_DEG`。
- `REACH_TIMEOUT` 已放大到 60s，堵转时最长 60s 才反向（属可接受的耐久测试兜底）。

## 验证

1. `build.bat` 编译无警告。
2. 上电观察：先到 +7200°，再回 0°，往复，全程带加减速、端点无突变/顿挫。
3. 日志无 `0x0200`（阶跃过大）、无「长时间未到达目标」误报。
