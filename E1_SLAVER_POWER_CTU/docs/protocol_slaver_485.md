# 副电源模块(从板) ↔ 主机 RS485 通信协议

- **作者**：maximillian
- **日期**：2026-09-03
- **版本**：V1.0.0（草案，待主机联调锁定）
- **摘要**：定义副电源管理模块 E1_SLAVER_POWER_CTU（STM32F103RCT7）与上位机/主机之间的 RS485 通信协议。板作为 **485 从站**，**主机查询应答式**：板不自主上报，仅应答主机查询/控制。

---

## 总线

| 项目 | 值 |
|------|----|
| 物理层 | RS485 半双工（USART3，PB10/PB11） |
| 收发器 | SP3485EN，DE/!RE 由 PC5（`RS485_EN`）控制，高=发送 |
| 波特率 | 115200-8N1 |
| 拓扑 | 主机为主站，本板为从站（单从机，帧内无地址字段） |

## 帧格式

与 E1_MASTER_POWER_CTU / G0 上位机串口协议一致（收发同构，变长负载）：

```
[ 'z' ][cmd][data_len][payload...][crc][ '\n' ]
```

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 `'z'` | 1B | 0x7A |
| cmd | 1B | 命令码；应答帧 cmd = `0x80 \| 下行命令码` |
| data_len | 1B | 负载长度（0..255） |
| payload | data_len B | 负载数据 |
| crc | 1B | CRC8，多项式 0x31、初值 0xFF（`get_CRC8_check_sum`），覆盖 `'z'..payload` |
| 帧尾 `'\n'` | 1B | 0x0A |

**帧总长 = data_len + 5**。多字节字段小端字节序。

## 命令表

| CMD | 方向 | 帧名 | 负载长度 | 说明 |
|-----|------|------|---------|------|
| `0x01` | 主机 → 板 | 读系统状态 | 0 | 应答 2B（byte0 故障位 / byte1 输出与锁存位） |
| `0x02` | 主机 → 板 | 读电压 | 0 | 应答 8B 电压（AUX/MOTOR/LSD1/LSD2 mV） |
| `0x03` | 主机 → 板 | 读温度/VDDA | 0 | 应答 4B（mcu_temp×100、vdda_mv） |
| `0x10` | 主机 → 板 | 输出控制 | 4 | 输出使能位域 + 补光亮度；应答 ACK |
| `0x11` | 主机 → 板 | 清除故障锁存 | 1 | payload[0]=0x01；应答 ACK |
| `0x1F` | 主机 → 板 | 升级请求（预留） | 1 | 本阶段应答不支持（0x7F, err=0x02） |

应答 CMD = `0x80 | 下行命令`（如读状态应答 `0x81`）。

### 错误码（0x7F 错误应答 payload[0]）

| 错误码 | 含义 |
|--------|------|
| `0x00` | 无错误（正常 ACK） |
| `0x01` | 未知命令 |
| `0x02` | 功能暂不支持 |
| `0x03` | 帧长度与命令不匹配 |

## 0x81 — 系统状态应答（2 字节位域）

| 字节 | 位 | 字段 | 描述 |
|------|-----|------|------|
| 0 | 0 | `err_24v` | 24V 降压电源故障（DC-DC 使能超时/运行期 PGD 丢失 → 锁存） |
| | 1 | `err_12v` | 12V_ISO 电源故障（使能超时/运行期丢失 → 锁存） |
| | 2 | `err_aux` | AUX 输入缺失/低于阈值（×23 分压 < 20V） |
| | 3 | `err_motor` | MOTOR 输入缺失/低于阈值 |
| | 4 | `err_lsd1` | LSD1 输出故障（使能后节点未到低电平/运行期异常 → 锁存） |
| | 5 | `err_lsd2` | LSD2 输出故障 |
| | 6-7 | 保留 | 恒 0 |
| 1 | 0 | `out_24v` | 24V 实际输出（ON） |
| | 1 | `out_12v` | 12V_ISO 实际输出（ON） |
| | 2 | `out_lsd1` | LSD1 实际输出（ON） |
| | 3 | `out_lsd2` | LSD2 实际输出（ON） |
| | 4 | `latch_active` | 存在故障锁存（需 0x11 清除后自动重试） |
| | 5-7 | 保留 | 恒 0 |

> 注：故障位语义 = 对应输出已**故障锁存**（使能超时或运行期好状态持续丢失 ≥100ms 防误关断后置位）。
> `err_aux`/`err_motor` 为母线输入缺失判定（仅上报，不锁存）。

## 0x82 — 电压应答（8 字节）

| 字节 | 字段 | 单位 | 描述 |
|------|------|------|------|
| 0-1 | `aux_mv` | mV (uint16 LE) | AUX 输入电压（220k/10k ×23 分压） |
| 2-3 | `motor_mv` | mV (uint16 LE) | MOTOR 输入电压（×23） |
| 4-5 | `lsd1_mv` | mV (uint16 LE) | LSD1 输出节点电压（100k/10k ×11 分压） |
| 6-7 | `lsd2_mv` | mV (uint16 LE) | LSD2 输出节点电压 |

## 0x83 — 温度/VDDA 应答（4 字节）

| 字节 | 字段 | 单位 | 描述 |
|------|------|------|------|
| 0-1 | `mcu_temp` | 0.01°C (int16 LE) | MCU 内部温度（°C×100） |
| 2-3 | `vdda_mv` | mV (uint16 LE) | 校准后 VDDA |

## 0x90 — 输出控制命令（主机 → 板，负载 4 字节）与 ACK

| 负载字节 | 字段 | 描述 |
|----------|------|------|
| 0 | `ctrl` | 输出使能位域（整帧覆盖期望态）：bit0=24V、bit1=12V_ISO、bit2=LSD1、bit3=LSD2 |
| 1 | 保留 | 恒 0x00 |
| 2-3 | `fill_duty` | 补光灯亮度 0..1000（uint16 LE，0.1% 精度；PT4115 DIM） |

板收到后：期望输出写入电源监督 FSM（按 24V→12V_ISO/LSD 依赖门控、PGOOD 门控 + 超时锁存），补光亮度立即应用到 TIM4_CH3；应答 `0x90` + payload[0]=`0x00`。实际生效状态通过 0x01 回读。

## 0x91 — 清除故障锁存

负载 1 字节（magic `0x01`）。清除全部故障锁存；锁存清除后电源监督 FSM 按当前期望输出自动重试使能。应答 `0x91` + payload[0]=`0x00`。

## 0x9F — 升级请求（预留）

负载 1 字节（magic `0x01`）。本阶段固件应答 `0x7F`，payload[0]=`0x02`（不支持）。
将来实现 RS485 固件升级时另行定义升级握手与烧写流程。

## 交互流程示例

| 步骤 | 主机 | 方向 | 板 |
|------|------|------|----|
| 1 | `z 01 00 crc \n`（读状态） | → | |
| 2 | | ← | `z 81 02 [状态2B] crc \n` |
| 3 | `z 10 04 0F 00 E8 03 crc \n`（24V+12V+LSD1+LSD2 全开，补光 100%） | → | 门控使能 |
| 4 | | ← | `z 90 01 00 crc \n` ACK |
| 5 | `z 11 01 01 crc \n`（清锁存） | → | 自动重试 |

## 软件映射

- 服务层 `srv_com_slv`：
  - 解析：`protocol_parser`（m_middlewares，header=`'z'`/footer=`'\n'`、长度字段回调、CRC8 校验回调）
  - 打包：`protocol_packer`（同一信封 + `fill_len_cb`/`checksum_cb` 回填 data_len 与 CRC8）
  - 语义：读状态/电压/温度经 `read_data` 回调取数，控制经 `ctrl` 回调应用，清锁存经 `reset_latch` 回调，应答帧经 `send_frame` 回调上抛
- 驱动层：`drv_uart`（USART3 DMA TX 队列 + RX circular/IDLE→kfifo）；`dev_rs485`（RS485_EN DE/RE 方向控制 + TX 完成自动释放总线）
- 任务层：`com_task` 每 10ms 搬运 dev_rs485 字节 → `srv_com_slv_rx_feed()`（含 `rx_tick` 空闲超时），并周期 `dev_rs485_tx_flush()` 排空
- 应用层：`app_status_report_fill` 聚合 `srv_pwr_ctrl`/`srv_adc`/`srv_pwr_det` 填充上报体，注册为 `read_data` 回调

## 未决/待实机确认
