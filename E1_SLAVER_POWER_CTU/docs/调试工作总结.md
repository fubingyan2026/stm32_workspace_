## 1. 阶段工作概述

在分层骨架基础上完成了「电源输出监督 FSM / 母线监控 / RS485 从机协议 / 上位机」的实机联调，并围绕实机日志解决了两类硬性问题（ISO12V 使能极性、MCU 内部温度恒 0）。

### 1.1 固件改动汇总

| 文件 | 改动 |
|----|----|
| service/srv_pwr_ctrl.c/h | 状态机重构：由手写 `switch(state)` 改为 **fsm 库实现**（与 E1_MASTER_POWER_CTU 同框架），4 路输出各持独立 `fsm_t` 实例，状态 OFF/ENABLING/ON/LATCHED；handler 表 + 全连通转换矩阵 + `fsm_step()` 按拍推进，行为语义保持不变 |
| tasks/power_task.c | 每 10ms 分频拍接入 `srv_pwr_det_read()` 周期轮询，使 PGOOD 遥测日志（内部 1s 限频）实时生效 |
| device_drivers/drv_power.c/h | `DRV_POWER_RAIL_ISO12V` 使能极性改 **低有效（active_low=true，PA4 拉低使能）** |
| device_drivers/drv_status.c/h | `DRV_STATUS_ISO12V_PGD` 保持**高有效**（PA5 高=好）；注释修正为实测语义 |
| service/srv_adc.c | MCU 内部温度换算：出厂校准缺失时由「输出 0 + ERR_CAL」改为**回退典型参数法**（V25=1430mV、4.3mV/℃） |
| docs/hardware_pin.md | PA4 ISO_EN_12V 低有效、PA5 高=好（均实测确认） |
| README.md | 登记 host/ 上位机 |

### 1.2 新增上位机（host/）

| 文件 | 说明 |
|----|----|
| host/slv_protocol.py | RS485 协议编解码：z 帧 + CRC8(0x31/0xFF)，命令 0x01 状态 / 0x02 电压 / 0x03 温度+VDDA / 0x10 输出控制 / 0x11 清锁存；与 `srv_com_slv.c` 及 docs/protocol_slaver_485.md 对齐 |
| host/slv_host.py | PySide6 + pyserial 上位机：串口连接、查询按钮、四路输出勾选 + 补光亮度滑条(0~1000, 0.1%)、全开/全关/清锁存、自动轮询、固定槽位数据区（未读取显示 `--` 不折叠）、带颜色日志 |

运行方式：`cd E1_SLAVER_POWER_CTU/host && python slv_host.py`。

### 1.3 通信协议

- 帧格式：`[z][cmd][data_len][payload][CRC8][\n]`，CRC8 多项式 0x31、初值 0xFF，总长 = data_len+5，多字节小端。
- 命令：0x01 读系统状态 / 0x02 读电压 / 0x03 读温度+VDDA / 0x10 输出控制 / 0x11 清除故障锁存 / 0x1F 升级预留（应答不支持）。
- 注意与 master 命令布局差异：0x02=电压、0x03=温度（master 为 0x02 温度、0x03 电压）；控制为输出掩码+补光亮度，非蜂鸣器。

## 2. 实机调试与日志分析

### 2.1 上电时序（正常段）

```
D(20)  DC_DC_EN(24V) 开启 → I(20) DC24V 开始使能 → I(48) DC24V 已就绪 (ON)
D(49)  ISO_EN_12V / LSD1 / LSD2 开启 → LSD1/LSD2 于 ~10ms 去抖后 ON
```

- DC24V（LM5146）使能、PGOOD 判定、去抖（10ms）均正常。
- LSD1/LSD2 经节点电压门控（使能后节点 <3V）正常就绪。

### 2.2 阻塞问题 A：ISO12V 使能超时（500ms）锁存

- 现象：ISO_EN_12V 拉高使能后 12V 一直未就绪，500ms 使能超时 → 故障锁存关断；锁存后（ISO_EN 拉低）PGOOD 反而持续 =1（数秒）。
- 推断与验证：PGOOD 经 LM193 窗口比较器 + 光耦隔离反馈，实测 **PA5 好=高电平**；结合日志（拉高不满足 / 拉低反而 12V 正常），确认问题在 **ISO_EN_12V 使能端极性反相** —— URB2412S 实际**拉低使能**（或板级驱动反相）。
- 修复：`drv_power.c` 中 `DRV_POWER_RAIL_ISO12V` 设 `active_low=true`；`drv_status.c` 中 ISO12V_PGD 保持高有效并修订注释/硬件文档。
- 遗留说明：若板上 ISO_EN 引脚经反相驱动（非模块 CTRL 直连），硬件文档方向需以实测为准，后续可再核对原理图。

### 2.3 阻塞问题 B：MCU 内部温度恒 0（mcuT=0）

- 现象：`srv_adc` 遥测 `mcuT=0(×100)` 恒定不变。
- 根因：F103 高密度器件的内部温度**出厂校准地址（0x1FFFF7B8/0x1FFFF7C2）通常读回 0xFFFF**；E1_SLAVER 原实现仅支持校准插值，校准无效时直接输出 0 并返回 `ERR_CAL`。
- 修复：参照 E1_MASTER，无校准值时**回退典型参数法**：
  - `V_sense = raw × VDDA / 4095`
  - `T = (V25 − V_sense) / 4.3 + 25`（V25=1430mV；F1 传感器电压随温度升高而下降，负斜率方向已确认）
  - 加 -50℃ ~ 150℃ 输出钳位。
- `calc_mcu_temp` 增加 `vdda_mv` 入参（与 master 签名对齐）。

## 5. 后续待办（建议优先级）

1. [高] ISO12V 修复后实机上电验证：使能后应 ~10ms 去抖进入 ON；同时复核原理图确认 ISO_EN_12V 反相来源（模块 CTRL 或板级驱动级）。
2. [中] 温度修复后实机确认 mcuT 读数合理（室温 20~40℃ 量级）；如与红外实测偏差大，考虑引入实测两点标定。
3. [中] 协议/上位机与量产联调锁定：命令码、状态位域、补光 0~1000 语义为草案 V1.0.0。
4. [低] AUX/MOTOR 输入存在阈值（20V）、LSD 节点就绪阈值（3V）、各使能超时（800/500/100ms）为默认值，待整机联调标定。
5. [低] 共享库 protocol_parser 告警清理可在兄弟工程范围内统一处理。
