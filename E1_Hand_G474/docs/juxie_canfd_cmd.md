# CAN FD 通信协议手册

---

## 1. 通信基础配置

* **协议类型**：CAN FD 加速 标准帧
* **仲裁段波特率**：1 Mbps
* **数据段波特率**：5 Mbps

---

## 2. 执行器反馈报文（执行器 $\rightarrow$ 上位机）

### 2.1 触发方式
1. **同步帧触发**：上位机发送同步报文（ID：`0x80`）。
2. **多控报文触发**：上位机发送多控报文触发执行器数据反馈。
3. **单轴控报文触发**：上位机发送单轴控制报文触发执行器数据反馈。

---

### 2.2 带力矩传感器反馈报文

* **CAN ID (StdID)**：`0x300 | Dev_ID`（11 bit）
* **帧长度 (DLC)**：16 字节

| 字节偏移 | 字段名称 | 类型/长度 | 内容说明（数据范围与单位） |
| :--- | :--- | :--- | :--- |
| `Byte[0~1]` | 负载端实际位置 | int16 (16bit) | `Byte[0]` 高8位，`Byte[1]` 低8位；`[-32768 ~ 32767]` 对应 $(-180^\circ \sim 180^\circ)$ |
| `Byte[2~3]` | 电机端实际速度 | int16 (16bit) | `Byte[2]` 高8位，`Byte[3]` 低8位；`[-32768 ~ 32767]`，单位：`RPM` |
| `Byte[4~5]` | 实际电流（Iq） | int16 (16bit) | `Byte[4]` 高8位，`Byte[5]` 低8位；`[-32768 ~ 32767]`，单位：`mA` |
| `Byte[6~7]` | 错误代码 | uint16 (16bit) | `Byte[6]` 高8位，`Byte[7]` 低8位；参考报错代码表 |
| `Byte[8~9]` | 电机线圈温度 | int16 (16bit) | `Byte[8]` 高8位，`Byte[9]` 低8位；单位：`0.1 ℃` |
| `Byte[10~11]`| 力矩反馈 | int16 (16bit) | `Byte[10]` 高8位，`Byte[11]` 低8位；单位：`0.05 Nm` |
| `Byte[12~13]`| 预留 | 16bit | 保留 |
| `Byte[14]` | 控制模式反馈 | uint8 (8bit) | `0x01`: 轮廓位置模式；`0x02`: 轮廓速度模式；<br>`0x03`: CSP位置模式；`0x04`: CSV速度模式；<br>`0x05`: 电流环模式；`0x06`: 力矩环模式 |
| `Byte[15]` | 执行器状态位 | 8bit | 按位定义见下表 |

**Byte[15] 状态位详细定义：**
* **Bit[7]**：使能状态（`0`：下使能，`1`：上使能）
* **Bit[6]**：抱闸状态（`0`：抱闸吸合，`1`：抱闸释放）
* **Bit[5]**：报错状态（`0`：正常状态，`1`：报错状态）
* **Bit[4]**：位置到位状态（`0`：运行中，`1`：运行到位）
* **Bit[3~0]**：预留

## 3. 标准控制报文（上位机 $\rightarrow$ 执行器）

### 3.1 单执行器控制报文

功能：用于单独控制指定电机。

* **CAN ID (StdID)**：`0x100 | Dev_ID`（11 bit）
* **帧长度 (DLC)**：7 字节

| 字节偏移 | 字段名称 | 类型/长度 | 内容说明 |
| :--- | :--- | :--- | :--- |
| **Byte[0]** | 控制指令头 | 8bit | **Bit[7]** 使能控制：`0` 下使能，`1` 上使能<br>**Bit[6]** 抱闸控制：`0` 抱闸吸合，`1` 抱闸释放<br>**Bit[5]** 清除错误：`0` 默认，`1` 复位错误<br>**Bit[4~1]** 控制模式：<br>&emsp;`0x01`: 轮廓位置模式<br>&emsp;`0x02`: 轮廓速度模式<br>&emsp;`0x03`: CSP位置模式<br>&emsp;`0x04`: CSV速度模式<br>&emsp;`0x05`: 电流环模式<br>&emsp;`0x06`: 力矩环模式<br>**Bit[0]**：预留（填 `0`） |
| **Byte[1~2]** | 目标参数 1 | 16bit | `Byte[1]` 高8位，`Byte[2]` 低8位：<br>1. **位置模式 (`0x01, 0x03`)**：输出端目标位置，`[-32768 ~ 32767]` 对应 $(-180^\circ \sim 180^\circ)$<br>2. **速度模式 (`0x02, 0x04`)**：电机端目标速度，`[-32768 ~ 32767]`，单位：`RPM`<br>3. **电流模式 (`0x05`)**：电机目标 Iq 电流，`[-32768 ~ 32767]`，单位：`mA`<br>4. **力矩模式 (`0x06`)**：电机目标力矩，`[-32768 ~ 32767]`，单位：`0.1 Nm` |
| **Byte[3~4]** | 目标参数 2 | 16bit | `Byte[3]` 高8位，`Byte[4]` 低8位：<br>1. **轮廓位置/速度模式 (`0x01, 0x02`)**：轮廓加减速，范围 `[0 ~ 20000]`，单位：`RPM/S` |
| **Byte[5~6]** | 目标前馈参数 | 16bit | `Byte[5]` 高8位，`Byte[6]` 低8位：<br>1. 预留前馈参数<br>2. **轮廓位置模式 (`0x01`)**：输出端的轮廓速度（单位：`RPM`） |

## 4. MIT 模式控制报文（上位机 $\rightarrow$ 执行器）

### 4.1 MIT 模式单执行器控制报文

功能：用于单独 MIT 模式控制指定电机。

* **CAN ID (StdID)**：`0x110 | Dev_ID`（11 bit）
* **帧长度 (DLC)**：9 字节

| 字节偏移 | 字段名称 | 长度 | 内容说明 |
| :--- | :--- | :--- | :--- |
| **Byte[0]** | 控制指令头 | 8bit | **Bit[7]** 使能控制：`0` 下使能，`1` 上使能<br>**Bit[6]** 抱闸控制：`0` 抱闸吸合，`1` 抱闸释放<br>**Bit[5]** 清除错误：`0` 默认，`1` 复位错误<br>**Bit[4:1]** 控制模式：`0x06` (MIT 模式)<br>**Bit[0]**：预留 |
| **Byte[1~2]** | 目标位置 | 16bit | `Byte[1]` 高8位，`Byte[2]` 低8位；`[0 ~ 65535]` 对应 $(-Pos\_Max \sim Pos\_Max)$ |
| **Byte[3] ~ Byte[4] Bit[7:4]** | 目标速度 | 12bit | `Byte[3]` 为高8位，`Byte[4]` 的 Bit[7:4] 为低4位；`[0 ~ 4095]` 对应 $(-Vel\_Max \sim Vel\_Max)$ |
| **Byte[4] Bit[3:0] ~ Byte[5]** | 位置增益 $K_p$ | 12bit | `Byte[4]` 的 Bit[3:0] 为高4位，`Byte[5]` 为低8位；`[0 ~ 4095]` 对应 $[0 \sim 500]$ |
| **Byte[6] ~ Byte[7] Bit[7:4]** | 速度增益 $K_d$ | 12bit | `Byte[6]` 为高8位，`Byte[7]` 的 Bit[7:4] 为低4位；`[0 ~ 4095]` 对应 $[0 \sim 5]$ |
| **Byte[7] Bit[3:0] ~ Byte[8]** | 目标力矩 | 12bit | `Byte[7]` 的 Bit[3:0] 为高4位，`Byte[8]` 为低8位；`[0 ~ 4095]` 对应 $(-T\_Max \sim T\_Max)$ |
