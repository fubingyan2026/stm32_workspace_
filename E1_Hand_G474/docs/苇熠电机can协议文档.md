# CAN通信协议开发文档（基于V1.04）

## 1. 概述
本协议适用于本公司伺服执行器（SCA）产品，基于CAN 2.0A标准，采用11位标识符（仅使用低8位作为设备地址），波特率1 Mbit/s。应用层支持数据帧和远程帧，最大节点数63个（实际最大64个，含广播地址0x00）。终端匹配电阻120Ω。

通信采用**小端字节序**（高字节在前，低字节在后），数据长度DLC表示后续字节数（0~8）。

---

## 2. 物理层与链路层参数
| 项目 | 规格 |
|------|------|
| 协议 | CAN 2.0A |
| CAN-ID类型 | 11位（仅低8位用于设备地址） |
| 波特率 | 1 Mbit/s |
| 最大站点数 | 63（地址0x01~0x3F推荐，0x00为广播） |
| 帧长度 | 0~8字节 |
| 终端电阻 | 120Ω |
| 推荐线径 | ≥0.205 mm² |
| 最大传输距离 | 25 m（典型） |

---

## 3. 数据帧格式
标准CAN数据帧包含：

| 字段 | 位数/字节 | 说明 |
|------|-----------|------|
| **设备地址** | 1字节（CAN-ID低8位） | 0x01~0xFF可用，0x00为广播地址 |
| **数据长度(DLC)** | 半字节（4位） | 实际数据字节数，范围0x00~0x0F（实际≤8） |
| **指令符** | 1字节 | 操作码（见指令表） |
| **参数内容** | 0~7字节 | 指令参数（长度 = DLC - 1） |

> **注意**：某些指令无参数内容，但DLC仍至少为1（仅含指令符）。

---

## 4. 数据格式（IQ定点数）
为了精确控制，本协议采用IQ格式，常见类型：

| IQ格式 | 缩放因子 | 取值范围 | 用途 |
|--------|----------|----------|------|
| IQ24 | 2²⁴（16,777,216） | -128.0 ~ +127.999999940 | 位置、PID参数、梯形曲线参数等 |
| IQ16 | 2¹⁶（65,536） | 仅用于MIT模式（位置值） | 特殊指令0x80/0x81 |
| IQ14 | 2¹⁴（16,384） | 仅用于MIT模式（速度/电流比例） | 特殊指令0x80/0x81 |
| IQ8 | 2⁸（256） | 用于部分读取指令（温度、带宽等） | 读取指令2类 |

### 4.1 转换公式
- **实际值 → IQ整数值**：`IQ = 实际值 × 2^n`（取整）
- **IQ整数值 → 实际值**：`实际值 = IQ ÷ 2^n`

### 4.2 各环满量程
- **位置**（IQ24）：满量程 ±127.0 转（R），IQ值即为实际转数。
- **速度**（IQ24或IQ14）：实际转速（RPM）= IQ值 ÷ 2^n × **6000 RPM**
- **电流**（IQ24或IQ14）：实际电流（A）= IQ值 ÷ 2^n × **满量程电流**（型号相关，如45A）

> **示例**：设置速度100 RPM，满量程6000 RPM。归一化值=100/6000≈0.0166667，IQ24 = 0.0166667 × 2²⁴ ≈ 279,620（0x00044444）。发送数据为0x09 00 04 44 44（指令0x09 + 4字节参数）。

---

## 5. 常用操作步骤（指令模式）
1. **使能**：发送 `0x2A 01`（设备地址 + DLC=2 + 指令0x2A + 参数0x01）
2. **选择模式**（DLC=2）：
   - 电流模式：`0x07 01`
   - 速度模式：`0x07 02`
   - 位置模式：`0x07 03`
   - S-位置模式：`0x07 06`
   - S-速度模式：`0x07 07`
   - HOMING模式：`0x07 08`
3. **抱闸操作**（若支持）：`0xF4 01`（打开） / `0xF4 00`（锁定）
4. **设定目标值**（如电流/速度/位置），非零值启动，零值停止。
5. **失能**：发送 `0x2A 00`（断电前必须执行，否则零位可能丢失）

## 6. 指令分类与格式
### 6.1 读取指令（按返回长度分类）

#### 6.1.1 发送1字节，返回2字节（读取指令1）
| 指令符 | 说明 |
|--------|------|
| 0x00 | 握手 |

| 0x80 | 查询上次失能状态 |
| 0x71 | 电流环滤波器状态 |
| 0x75 | 速度环滤波器状态 |
| 0x79 | 位置环滤波器状态 |
| 0x8B | 位置限位状态 |

#### 6.1.2 发送1字节，返回3字节（读取指令2，IQ8格式）

| 0x45 | 执行器电压（×2¹⁰倍） | 2字节，单位V |

| 0x60 | 逆变器温度（℃） | 2字节（IQ8） |
| 0x62/0x64 | 逆变器保护/恢复温度 | 2字节（IQ8） |
| 0x6C/0x6E | 电机保护/恢复温度 | 2字节（IQ8） |
| 0xFF | 报警指令（特殊） | 2字节报警码（见错误表） |
| 0x2B | 使能/失能状态 | 1字节（0x01/0x00） |
| 0x87 | 供电电压（×100倍） | 2字节，单位V（仅使能时刷新） |

> 返回格式：`[指令符][数据高位][数据低位]`（共3字节）

#### 6.2.1 发送2字节，返回2字节（写入指令1）
| 指令符 | 说明 | 参数（1字节） |

|--------|------|---------------------|
| 0x08 | 设置当前电流值 | 归一化值（×满量程） |

| 0xFE | 清除报警 |

#### 6.2.5 发送6字节，返回2字节（写入指令5）
| 指令符 | 说明 | 参数（6字节） |
|--------|------|---------------|
| 0x3D | 修改设备ID | 前6字节为序列号，第7字节（实际第6字节）为新ID |

> 参数结构：`[指令0x3D][序列号6字节][新ID]`，共8字节？原文说“发送数据时，第一字节为指令，中间六字节为序列号，第八字节为新ID号”，但表格标题“发送6字节”可能笔误，实际应为8字节（DLC=8）。开发时按实际需求处理。

#### 6.2.6 发送8字节，返回2字节或8字节（写入指令6，MIT模式）
| 指令符 | 说明 | 参数 |
|--------|------|------|
| 0x80 | 设置MIT模式位置/速度/电流 | 3字节(IQ16位置) + 2字节(IQ14速度归一化) + 2字节(IQ14电流归一化) + 1字节(PVC标志) |
| 0x81 | 设置MIT模式kp,kd | 3字节(IQ16 kp) + 3字节(IQ16 kd) + 1字节(PVC标志) + 1字节填充? |

> **PVC标志**：若为1，返回8字节数据（同0x94格式）；若为0，返回2字节状态。

## 8. 错误码（报警指令0xFF返回，或通过读取0xFF）
错误码为16位，可组合（如0x0005表示过压+堵转）。

| 错误码 | 含义 | 原因/解决 |
|--------|------|-----------|
| 0x0001 | 过压异常 | 电压>64V，检查电源/电容 |
| 0x0002 | 欠压异常 | 电压<18V，检查电源 |
| 0x0004 | 堵转异常 | 位置不动电流过大，检查机械 |
| 0x0008 | 过热异常 | 电机温度超保护值，降温 |
| 0x0010 | 读写参数异常 | 联系售后 |
| 0x0020 | EtherCAT通信异常 | 检查EC线 |
| 0x0040 | 位置超差 | 检查PID/阈值 |
| 0x0080 | CAN通信异常 | 联系售后 |
| 0x0100 | 速度超差 | 检查PID/阈值 |
| 0x0200 | 阶跃过大 | 位置阶跃>6R或速度阶跃>600RPM，减小阶跃 |
| 0x0400 | DRV保护 | 联系售后 |
| 0x0800 | 编码器故障 | 联系售后 |
| 0x1000 | 多圈错误 | 检查电池，执行多圈同步 |
| 0x2000 | 抱闸故障 | 无抱闸则设保护等级0，否则售后 |
| 0x4000 | 末端编码器故障 | 联系售后 |
| 0x8000 | 初始化失败 | 上电时勿转动电机，稳定供电 |
| 0x10000 | 电机缺相 | 联系售后 |
| 0x20000 | 母线过流 | 联系售后 |
| 0x80000 | 校准错误 | 联系售后 |
| 0x100000 | 逆变器过温 | 联系售后 |
| 0x200000 | 电机过温 | 联系售后 |
| 0x400000 | IMU初始化失败 | 联系售后 |
| 0x800000 | IAP错误 | 升级失败，重试或售后 |

## 9. 注意事项
- **字节顺序**：所有多字节参数均为**大端**（高字节在前）。
- **使能/失能**：每次上电后必须先使能（0x2A 01）才能操作；断电前务必失能（0x2A 00），否则零位可能丢失。
- **广播地址**：0x00可同时控制所有设备，但无返回。
- **心跳机制**：使能心跳后（0xE0 0100），需在设定时间内收到CAN帧，否则速度置0并报警。
- **IQ转换**：计算时注意满量程值（电流因型号而异，速度统一6000 RPM）。
- **滤波器状态**：滤波器的使能/失能指令（0x70/0x74/0x78）参数为1字节，返回2字节。

## 10. 快速参考：常见操作命令示例
| 功能 | 发送数据（十六进制） |
|------|----------------------|
| 使能（ID=1） | `01 02 2A 01` |
| 失能（ID=1） | `01 02 2A 00` |
| 设置位置模式（ID=1） | `01 02 07 03` |
| 设置速度模式（ID=1） | `01 02 07 02` |
| 设置电流模式（ID=1） | `01 02 07 01` |

| 读取当前速度（ID=1） | `01 01 05` |

| 清除报警（ID=1） | `01 01 FE`（返回2字节） |
| 查询模式（ID=1） | `01 01 55`（返回2字节） |
