CAN 配置为：标准帧、经典 CAN、仲裁波特率 1 Mbps、DLC=7。
**1\. 查询 Mz**
发送帧：

```
CAN ID：0x510
数据：04 00 00 00 00 00 00
周期：默认每 10 ms 一次
```

字段解析：
Byte0:04,读取功能码
Byte1\~2:00 00,Mz 数据地址 0x0000
Byte3\~6:00 00 00 00,请求占位
反馈帧：

```
CAN ID：0x410
数据：04 00 00 xx xx xx xx
```

反馈字段：
Byte0:04,读取功能码
Byte1\~2:00 00,Mz 地址
Byte3\~6:xx xx xx xx,大端 IEEE\-754 float32，单位 N·m
实测示例：

```
接收：0x410  04 00 00 BF 4A 3D 71
```

数据解析：

```
原始浮点字节：BF 4A 3D 71
字节序：大端
float32：约 -0.79000002
结果：Mz ≈ -0.79 N·m
```

Python解析方式：

```
import struct

payload = bytes.fromhex("04 00 00 BF 4A 3D 71")
mz_nm = struct.unpack(">f", payload[3:7])[0]
print(mz_nm)  # -0.7900000214576721
```

**2\. Mz标零**
发送帧：

```
CAN ID：0x510
数据：10 46 04 3F 80 00 00
```

字段解析：
Byte0:10,写入功能码
Byte1\~2:46 04,Mz标零寄存器 0x4604
Byte3\~6:3F 80 00 00,大端 float32 的 1\.0，执行通道1标零
按照当前协议写应答格式，预期返回：

```
CAN ID：0x410
数据：10 46 04 3F 80 00 00
```

应答解析：
Byte0:10,写操作应答
Byte1\~2:46 04,标零寄存器地址
Byte3\~6:3F 80 00 00,float32 1\.0，表示命令已接受
