## 一、物理层与基本参数

| 项目 | 说明 |
|------|------|
| **物理接口** | CAN（差分），支持标准 CAN 2.0A（11 位 ID） |
| **默认波特率** | **500 kbps**（可通过参数修改，最大 1 Mbps） |
| **默认节点 ID** | **0**（通过 `odrv0.axis0.config.can.node_id` 设置，范围 0~63） |
| **终端电阻** | 内部软件可控 120Ω（`odrv0.can.config.enable_r120 = True`） |
| **帧格式** | 标准帧（11 位 ID），数据长度 8 字节 |
| **字节序** | **小端模式**（Little-Endian） |
| **浮点数编码** | IEEE 754 单精度（32 位） |

> **采样点**：手册未明确给出，但基于 ODrive 平台，通常默认为 **87.5%**。建议实测或联系厂家确认。

## 二、支持的 CAN 协议栈

该驱动支持两种 CAN 高层协议，通过参数切换：

| 协议 | 参数值 (`odrv0.can.config.protocol`) | 说明 |
|------|--------------------------------------|------|
| **CAN Simple** | 1（默认） | 轻量级自定义协议，简单易用，适用于快速控制 |
| **CANOpen** | 2 | 符合 CiA 301 / 402 标准，支持标准运动控制模式 |

**物理接口复用**：CAN 与 RS485、PWM、Step/Dir 共用引脚，通过 `odrv0.config.comm_intf_mux` 选择：
- `0`：CAN
- `1`：RS485
- `2`：Step/Dir
- `3`：PWM

## 三、CAN Simple 协议详解

### 3.1 协议帧格式

```
CAN ID (11 bits) = [node_id (bits 10..5)] + [cmd_id (bits 4..0)]
Data = 8 bytes (小端)
```

- `node_id`：设备地址，范围 0~63
- `cmd_id`：命令码，见下表

### 3.2 命令码列表（全部可用消息）

| CMD ID | 名称 | 方向 | 说明 | 数据格式 |
|--------|------|------|------|----------|
| 0x01 | Heartbeat | 电机→主机 | 心跳状态，含错误、状态、温度等 | 见 3.3 |
| 0x02 | Estop | 主机→电机 | 紧急停止（发送 8 字节 0） | 无参数 |
| 0x03 | Get_Error | 主机→电机 | 请求详细错误码（需指定错误类型） | 输入：1字节错误类型；输出：对应错误码 |
| 0x04 | RxSdo | 主机→电机 | 读写任意参数（端点访问） | 见 3.4 |
| 0x05 | TxSdo | 主机→电机 | 同 RxSdo 写操作 | 同 RxSdo |
| 0x06 | Set_Axis_Node_ID | 主机→电机 | 设置节点 ID（4 字节 uint32） | - |
| 0x07 | Set_Axis_State | 主机→电机 | 设置电机请求状态（如空闲、闭环、校准） | 4 字节 uint32 |
| 0x08 | Mit_Control | 双向 | MIT 模式控制（位置/速度/力矩/KP/KD，压缩为 8 字节） | 按位域打包，见用户手册 |
| 0x09 | Get_Encoder_Estimates | 电机→主机 | 获取编码器位置（float32，转）和速度（float32，转/秒） | 8 字节：pos + vel |
| 0x0A | Get_Encoder_Count | 电机→主机 | 获取多圈计数（int32）和单圈计数（int32） | 8 字节 |
| 0x0B | Set_Controller_Mode | 主机→电机 | 设置控制模式（control_mode + input_mode） | 两个 uint32 |
| 0x0C | Set_Input_Pos | 主机→电机 | 设置目标位置（float32 转）+ 速度前馈（int16 0.001转/秒）+ 力矩前馈（int16 0.001Nm） | 4+2+2 字节 |
| 0x0D | Set_Input_Vel | 主机→电机 | 设置目标速度（float32 转/秒）+ 力矩前馈（float32 Nm） | 4+4 字节 |
| 0x0E | Set_Input_Torque | 主机→电机 | 设置目标力矩（float32 Nm） | 4 字节 |
| 0x0F | Set_Limits | 主机→电机 | 设置速度限制（float32 转/秒）和电流限制（float32 A） | 4+4 字节 |
| 0x10 | Start_Anticogging | 主机→电机 | 启动力矩纹波校准（发送 8 字节 0） | - |
| 0x11 | Set_Traj_Vel_Limit | 主机→电机 | 梯形轨迹速度限制（float32 转/秒） | 4 字节 |
| 0x12 | Set_Traj_Accel_Limits | 主机→电机 | 梯形轨迹加速度/减速度限制（两个 float32，转/秒²） | 4+4 字节 |
| 0x13 | Set_Traj_Inertia | 主机→电机 | 设置惯量（float32 Nm/(转/秒²)） | 4 字节 |
| 0x14 | Get_Iq | 电机→主机 | 获取 Q 轴电流目标值（float32 A）和实测值（float32 A） | 4+4 字节 |
| 0x15 | Get_Thermistor_Temperature | 电机→主机 | 获取电机温度（float32 ℃）和驱动温度（float32 ℃） | 4+4 字节 |
| 0x16 | Reboot | 主机→电机 | 重启驱动器（发送 8 字节 0） | - |
| 0x17 | Get_Bus_Voltage_Current | 电机→主机 | 获取母线电压（float32 V）和电流（float32 A） | 4+4 字节 |
| 0x18 | Clear_Errors | 主机→电机 | 清除所有错误（发送 8 字节 0） | - |
| 0x19 | Set_Move_Incremental | 主机→电机 | 相对增量移动（float32 转，转子侧） | 4 字节 |
| 0x1A | Set_Pos_Gain | 主机→电机 | 设置位置环 Kp（float32 (转/秒)/转） | 4 字节 |
| 0x1B | Set_Vel_Gains | 主机→电机 | 设置速度环 Kp（float32 Nm/(转/秒)）和 Ki（float32 Nm/转） | 4+4 字节 |
| 0x1C | Get_Torques | 电机→主机 | 获取力矩目标值（float32 Nm）和当前力矩（float32 Nm） | 4+4 字节 |
| 0x1D | Get_Powers | 电机→主机 | 获取电功率（float32 W）和机械功率（float32 W） | 4+4 字节 |
| 0x1E | Disable_Can | 主机→电机 | 禁用 CAN 并重启（发送 8 字节 0） | - |
| 0x1F | Save_Configuration | 主机→电机 | 保存参数并重启（发送 8 字节 0） | - |

### 3.3 心跳消息 (0x01) 数据格式

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| 0~3 | Axis_Error | uint32 | 驱动异常码（`odrv0.axis0.error`） |
| 4 | Axis_State | uint8 | 当前状态（1=空闲, 3=完全校准, 4=电机校准, 7=编码器校准, 8=闭环, 11=回零） |
| 5 | Flags | uint8 | bit0: 电机异常, bit1: 编码器异常, bit2: 控制异常, bit3: 系统异常, bit7: 轨迹完成 |
| 6 | Temperature | int8 | 电机/驱动最高温度（℃），最大值 127 |
| 7 | Life | uint8 | 心跳计数器（每帧+1），用于检测丢帧 |

### 3.4 端点访问 (RxSdo / TxSdo) 机制

- 通过 `Endpoint_ID`（16 位）读写任意参数（如 `vel_limit`、`current_lim` 等）。
- 需下载对应固件版本的 `endpoints_*.json` 文件（手册中提供链接）。
- 请求帧格式：
  - `byte0`：opcode（0=读，1=写）
  - `byte1~2`：Endpoint_ID（小端 uint16）
  - `byte3`：保留
  - `byte4~7`：写入值（4 字节，按端点类型解释为 int/float）
- 响应帧：opcode=0，返回读取值（4 字节）。

### 3.5 周期性消息配置

可通过以下参数配置电机主动上报（单位 ms，设为 0 则禁用）：

| 消息 | 配置参数 | 默认值 |
|------|----------|--------|
| Heartbeat | `odrv0.axis0.config.can.heartbeat_rate_ms` | 100 |
| Encoder Estimates | `odrv0.axis0.config.can.encoder_rate_ms` | 10 |
| Motor Error | `odrv0.axis0.config.can.motor_error_rate_ms` | 0 |
| Encoder Error | `odrv0.axis0.config.can.encoder_error_rate_ms` | 0 |
| Controller Error | `odrv0.axis0.config.can.controller_error_rate_ms` | 0 |
| Iq | `odrv0.axis0.config.can.iq_rate_ms` | 0 |
| Bus VI | `odrv0.axis0.config.can.bus_vi_rate_ms` | 0 |

> **注意**：`Get_Encoder_Estimates` 仅在闭环状态输出有效数据。

## 四、CANOpen 协议 (CiA 301/402)

### 4.1 基本框架

- 符合 CiA 301 通信规范，支持 PDO、SDO、NMT、心跳。
- 符合 CiA 402 驱动行规，支持多种操作模式：轮廓位置、周期同步位置/速度/力矩、回零等。
- 对象词典（EDS 文件）下载地址：`https://bl.cyberbeast.cn/actuator/ds402.eds`

### 4.2 COB-ID 分配（标准）

| 对象 | 功能码 | COB-ID 范围 |
|------|--------|-------------|
| NMT | 0000b | 0x000 |
| SYNC | 0001b | 0x080 |
| 紧急报文 | 0001b | 0x080 + Node_ID |
| TPDO1~4 | 0011b,0101b,0111b,1001b | 0x180+ID, 0x280+ID, 0x380+ID, 0x480+ID |
| RPDO1~4 | 0100b,0110b,1000b,1010b | 0x200+ID, 0x300+ID, 0x400+ID, 0x500+ID |
| TSDO | 1100b | 0x600+ID |
| RSDO | 1011b | 0x580+ID |
| 心跳 (NMT) | 1110b | 0x700+ID |

### 4.3 支持的操作模式（6060h / 6061h）

| 模式值 | 名称 | 说明 |
|--------|------|------|
| 1 | 轮廓位置模式 (Profile Position) | 带梯形轨迹规划的位置控制 |
| 6 | 回零模式 (Homing) | 寻找参考点/清零 |
| 8 | 周期同步位置模式 (CSP) | 主机周期下发位置指令 |
| 9 | 周期同步速度模式 (CSV) | 主机周期下发速度指令 |
| 10 | 周期同步力矩模式 (CST) | 主机周期下发力矩指令 |

### 4.4 关键对象字典（部分）

| 索引 | 子索引 | 名称 | 类型 | 说明 |
|------|--------|------|------|------|
| 6040h | - | 控制字 | Uint16 | 状态机控制（使能、运行、停止等） |
| 6041h | - | 状态字 | Uint16 | 当前状态及标志 |
| 6060h | - | 操作模式 | Int8 | 设置控制模式 |
| 6061h | - | 操作模式显示 | Int8 | 当前模式 |
| 6064h | - | 实际位置 | Int32 | 当前位置（指令单位） |
| 607Ah | - | 目标位置 | Int32 | 位置指令 |
| 60FFh | - | 目标速度 | Int32 | 速度指令 |
| 6071h | - | 目标转矩 | Int16 | 力矩指令（0.1% 额定转矩） |
| 6077h | - | 实际转矩 | Int16 | 当前力矩 |
| 6098h | - | 回零方式 | Int8 | 支持 17 和 35（35 用于清零） |
| 6081h | - | 轮廓速度 | Uint32 | 梯形速度限值 |
| 6083h | - | 轮廓加速度 | Uint32 | 梯形加速度 |
| 6084h | - | 轮廓减速度 | Uint32 | 梯形减速度 |
| 605Ah | - | 快速停机方式 | Int16 | 停机斜坡选择 |
| 605Ch | - | 停机方式 | Int16 | 使能关闭停机方式 |
| 605Dh | - | 暂停方式 | Int16 | 暂停停机方式 |
| 605Eh | - | 故障停机方式 | Int16 | 故障停机方式 |

> **指令单位**：与转换因子（`608Fh`、`6091h`）相关，默认与转子侧转数成比例，具体参见手册补充说明。

### 4.5 PDO 映射（默认）

- **RPDO1**：控制字 (6040h) + 操作模式 (6060h)
- **RPDO2**：控制字 + 目标位置 (607Ah)
- **RPDO3**：控制字 + 目标速度 (60FFh)
- **RPDO4**：控制字 + 目标转矩 (6071h)
- **TPDO1**：状态字 (6041h) + 操作模式显示 (6061h)
- **TPDO2**：状态字 + 实际位置 (6064h)
- **TPDO3**：状态字 + 实际速度 (606Ch)
- **TPDO4**：状态字 + 实际转矩 (6077h)

PDO 映射可自定义（通过 SDO 修改 1600h~1A03h）。

### 4.6 主站监控（心跳消费）

- 驱动可作为心跳消费者，监控主站是否在线。
- 配置 `1016h` 子索引（1~8），每个子索引为 32 位：高 8 位保留，中 8 位为节点 ID，低 16 位为超时时间（ms）。
- 同时驱动作为心跳生产者，`1017h` 配置生产者周期（默认 500 ms）。

### 4.7 SDO 通信

- 使用加速 SDO（支持 4 字节以内读写）。
- 帧格式：命令码（1字节）+ 索引（2字节，小端）+ 子索引（1字节）+ 数据（4字节）。
- 写命令：0x23（4字节）/0x2B（2字节）/0x2F（1字节）。
- 读命令：0x40，响应：0x43（4字节）/0x4B（2字节）/0x4F（1字节）。

## 五、错误码机制

### 5.1 CAN Simple 错误获取

- **心跳 Flags** 提供初步错误指示（bit0~3）。
- 使用 `Get_Error`（CMD 0x03）指定错误类型获取详细 32/64 位错误码：
  - `Error_Type=0`：电机错误（64 位）
  - `Error_Type=1`：编码器错误（32 位）
  - `Error_Type=3`：控制错误（32 位）
  - `Error_Type=4`：系统错误（32 位）

### 5.2 CANOpen 错误获取

- 状态字 6041h 的 bit3 指示故障。
- 读取对象 603Fh（16 位标准故障码），若为 `0xFF00` 则进一步读取 203Fh（32 位厂商特定码）和 203Eh（高 32 位扩展）。
- 错误代码分类符合 CiA 402 标准（电流、电压、温度、通信、厂商等）。

### 5.3 常见错误码速查（节选）

| 错误类别 | 错误码 (ODrive) | 名称 | 说明 |
|----------|----------------|------|------|
| 系统 | 0x00000002 | DC_BUS_UNDER_VOLTAGE | 欠压 |
| 系统 | 0x00000004 | DC_BUS_OVER_VOLTAGE | 过压 |
| 驱动 | 0x00001000 | MIN_ENDSTOP_PRESSED | 下限位触发 |
| 驱动 | 0x00004000 | ESTOP_REQUESTED | 紧急停止 |
| 电机 | 0x00020000 | MOTOR_THERMISTOR_OVER_TEMP | 电机过热 |
| 电机 | 0x00040000 | FET_THERMISTOR_OVER_TEMP | 驱动过热 |
| 电机 | 0x00000400 | CURRENT_SENSE_SATURATION | 电流采样饱和 |
| 编码器 | 0x00000002 | CPR_POLEPAIRS_MISMATCH | 极对数与 CPR 不匹配 |
| 控制 | 0x00000001 | OVERSPEED | 超速 |

完整错误码表见《驱动协议手册》第 4 章。

## 六、通信超时与安全机制

- **超时停止**：通过 `odrv0.can.config.break_timeout`（单位 ms）设置。从第一次收到 CAN 指令开始，若间隔超过此时间，电机报错并停止。默认 0（关闭）。
- **CANOpen 消费者心跳**：也可实现主站掉线监控（见 4.6）。

## 七、开发建议

1. **初始配置**：上电后先用 NMT（CANOpen）或 Set_Axis_State（CAN Simple）将电机从空闲切换至闭环。
2. **校准**：首次使用或恢复默认参数后，需执行电机校准和编码器校准（可通过命令触发）。
3. **协议选择**：若只需基础控制，推荐 **CAN Simple**，命令简单、实时性好；若需标准工业兼容，使用 **CANOpen**。
4. **周期消息**：合理配置心跳和反馈周期，避免总线负载过高。
5. **错误处理**：定期读取心跳或状态字，并检查错误标志，及时响应异常。
