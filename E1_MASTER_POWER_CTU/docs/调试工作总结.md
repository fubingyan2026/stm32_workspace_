## 1. 架构与已落地功能

在 E1_Master_Power_Manage 分层架构上落地可编译固件（Debug 构建 RAM≈11024B/48K、FLASH≈76KB/256K，工程自身 0 告警）。

- **device_drivers**：drv_systick / drv_adc(ADC1 7ch DMA，含 recover 三级复位) / drv_cd4051b / drv_pwm(TIM4 LED+双风扇 25k) / drv_led / drv_buzzer(TIM3_CH3, 导通 0-50%) / drv_fan(EXTI FG) / drv_power / drv_status / drv_log_uart(USART1) / drv_uart(USART3 DMA TX队列+RX circular/IDLE→kfifo) / dev_rs485(DE/RE)
- **service**：srv_adc(VREFINT+MCU 温度典型参数+CD4051B 双冗余+判稳窗口) / srv_pwr_ctrl(输入门控 5 步上电+过压保护) / srv_pwr_det(双判据+使能门控监测) / srv_fan_ctrl(可宏屏蔽 FG) / srv_com_mst(z 帧+addr，V4)
- **applications**：app_fault_policy(急停只控 MOTOR+PGD settle/debounce) / app_status_report / app_status_indicator
- **tasks**：app_main / com_task(可带 485 低频自检) / fan/led/sample/power_task / log_task(UART+RTT)
- **host**：`ctu_host.py`/`ctu_protocol.py`（PySide6：主/从寻址、查询、蜂鸣 0-50、自动轮询、固定槽位数据区、收发帧显示）

## 2. 最终电源语义

| 项 | 规则 |
|----|----|
| 使能前提 | 输入 VIN∈[36,58]V 才允许使能任何输出；超范围四路不使能 + 蜂鸣器周期上报 |
| 上电流程 | VIN 合格 → VIN_DC-DC≥90%VIN → 使能 VIN_DC-DC_EN(+100ms) → 使能 DC_DC_24V_EN → 双 PGD(DC24V+LM5060) 高=成功 |
| AUX | 输入有效后即使能（不依赖其它轨成功）；不再无条件“初始化直开” |
| 低压(<36V) | 已上电后**不关断**输出（仅监测） |
| 过压(≥60V) | 持续 5s → 关断全部输出并锁存；回落 ≤58V 自动清锁存重启 |
| 急停 | **只控制 MOTOR**；VIN/24V/AUX 不被急停关断 |
| MOTOR | 未锁存+已上电+未急停才使能；使能前请求延后(POWERED 自动生效)；MOTOR PGD 判定带 150ms settle+50ms debounce；485 0x05 可清锁存 |

## 3. 实机调试完成/结论

1. **上电步骤 5 卡双 PGD**：LM5060_PGD 在 24V 使能后 ~20ms 掉低（母线仍在），倾向硬件 PGOOD 网络/24V 冲击——待硬件确认（遗留）。
2. **MCU 温度恒 0 / 加热反向下降**：F103 无出厂校准 → 典型参数兜底；斜率符号为 F1 负斜率，已修正（加热读数上升）。
3. **急停双判据**：CD4051B 按 Y0/1、Y2/3…=ADC1/ADC2 组对；闭合掩码带 50ms 判稳窗口；按下/释放过程冗余“偏差异常”加抑制（500ms+按下态）避免误报。
4. **485 高频查询导致 ADC 停采**：DMA 完成回调偶发丢失→busy 卡死；新增“无快照看门狗”→`drv_adc_recover`（Stop→Start→DeInit/MspInit/MX 三级）自动恢复；已连续稳定读取。
5. **状态灯“恢复正常后仍闪烁”**：srv_signal 闪烁更新命令回推队列导致旧 BLINK 覆盖呼吸命令；已修共享库（非 BLINK 命令后丢弃旧 BLINK 更新），API 不变。
6. **MOTOR 使能即误关**：PGD 未稳定即判故障 → 150ms settle + 50ms debounce（日志重复关闭也已清理）。
7. **风扇无 FG**：`SRV_FAN_CTRL_TACH_BYPASS=1` 屏蔽自检/堵转/上报（视作正常），量产接 FG 后置 0。
8. **CD4051B 轮询**：改为“本周期转换完成后在 step 预选下一通道”的无阻塞方式，下周期采样前有整周期稳定时间。

## 5. 遗留与建议

1. [高] LM5060_PGOOD 硬件排查（上电双 PGD 完成需两路稳定高）。
2. [中] NTC1 探头参数/分压标定（当前读数≈-44℃）；MCU 温度典型参数如需更高精度做单/两点校准。
3. [中] 485 与 E1_SLAVER 双板共线联调锁定（帧/命令已统一）。
4. [低] 共享库 protocol_parser 3 条既有告警清理；`drv_uart_recover()` 周期兜底未接入。
5. [低] 5 步上电/过压恢复为自动策略（如需人工复位可加选项）；485 低频自检(`COM_TEST_TX_ENABLE`)联调后置 0。
