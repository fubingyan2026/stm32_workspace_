# 主电源板(CTU) ↔ 主机 RS485 通信协议

- **作者**：maximillian
- **日期**：2026-09-03
- **版本**：V2.0.0（草案，待主机联调锁定）
- **摘要**：定义量产主控板 E1_MASTER_POWER_CTU（STM32F103RC）与上位机/主机之间的 RS485 通信协议。板作为 **485 从站**，**主机查询应答式**：板不自主上报，仅应答主机查询/控制。

---

## 总线

| 项目 | 值 |
|------|----|
| 物理层 | RS485 半双工（USART3，PB10/PB11） |
| 收发器 | SP3485EN，DE/!RE 由 PC5（`RS485_EN`）控制，高=发送 |
| 波特率 | 115200-8N1 |
| 拓扑 | 主机为主站，本板为从站（单从机，帧内无地址字段） |

## 帧格式

与 G0 上位机串口协议一致（收发同构，变长负载）：

```
[ 'z' ][cmd][data_len][payload...][crc][ '\n' ]
```

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 `'z'` | 1B | 0x7A |
| cmd | 1B | 命令码；应答帧 cmd = `0x80 \| 下行命令码` |
| data_len | 1B | 负载长度（0..255） |
| payload | data_len B | 负载数据 |
| crc | 1B | CRC8，多项式 0x31、初值 0xFF（`get_CRC8_check_sum`），覆盖 `'z'..payload` |
| 帧尾 `'\n'` | 1B | 0x0A |

**帧总长 = data_len + 5**。多字节字段小端字节序。

## 命令表

| CMD | 方向 | 帧名 | 负载长度 | 说明 |
|-----|------|------|---------|------|
| `0x01` | 主机 → 板 | 读系统状态 | 0 | 应答 2B 状态位域 |
| `0x02` | 主机 → 板 | 读温度 | 0 | 应答 6B 温度（NTC1/NTC2/MCU ×100℃） |
| `0x03` | 主机 → 板 | 读电压 | 0 | 应答 4B 电压（VIN / VIN_DC-DC mV） |
| `0x10` | 主机 → 板 | 控制 | 1 | buzzer_duty；应答 ACK(1B)=0x00 |
| `0x11` | 主机 → 板 | 升级请求（预留） | 1 | 本阶段应答不支持（0x7F, err=0x02） |
| `0x7F` | 板 → 主机 | 错误应答 | 1 | payload[0]=错误码，见下 |

应答 CMD = `0x80 | 下行命令`（如读状态应答 `0x81`）。

### 错误码（0x7F 错误应答 payload[0]）

| 错误码 | 含义 |
|--------|------|
| `0x00` | 无错误（正常 ACK） |
| `0x01` | 未知命令 |
| `0x02` | 功能暂不支持 |
| `0x03` | 帧长度与命令不匹配 |

## 0x81 — 系统状态应答（2 字节位域）

| 字节 | 位 | 字段 | 描述 |
|------|-----|------|------|
| 0 | 0 | `stop_key_state` | 急停：0=释放, 1=按下（有效急停，见注） |
| | 1 | `err_12v` | 12V 电源异常（PGOOD_12V） |
| | 2 | `err_24v` | 24V 降压电源异常（DC_DC_24V_PGOOD） |
| | 3 | `err_vin_dcdc` | VIN_DC-DC 前端异常（LM5060_PGOOD） |
| | 4 | `err_aux_power` | 辅助电源异常（AUX PGD） |
| | 5 | `err_motor_power` | 电机电源异常（急停未按下 且 MOTOR_PGD=0） |
| | 6-7 | 保留 | 恒 0 |
| 1 | 0 | `err_fan0` | 风扇0 异常 |
| | 1 | `err_fan1` | 风扇1 异常 |
| | 2 | `err_ntc1` | NTC1 未连接 |
| | 3 | `err_ntc2` | NTC2 未连接 |
| | 4-7 | 保留 | 恒 0 |

> 注：电源轨 PGD 位未按「使能门控」处理（EN=0 时上报原始 PGD 状态）；
> 如需区分掉电中/故障可后续在协议中增加上电状态字段。
>
> 注：`stop_key_state` 为“有效急停”——数字 E_STOP_ON(PC9) 按下 **且** CD4051B 冗余侧检出断开
> 才置 1。冗余侧为 4 组 E-STOP 双冗余节点（偶数 mux 通道=ADC1、奇数=ADC2，Y0/1、Y2/3…），
> 两节点电平一致判闭合、互补判断开；仅数字按下属判据不一致，上报仍为 0 并以本板日志告警
> （固件不因此触发断电）。

## 0x82 — 温度应答（6 字节）

| 字节 | 字段 | 单位 | 描述 |
|------|------|------|------|
| 0-1 | `ntc1_temp` | 0.01°C (int16 LE) | NTC1 温度（°C×100） |
| 2-3 | `ntc2_temp` | 0.01°C (int16 LE) | NTC2 温度（°C×100） |
| 4-5 | `mcu_temp` | 0.01°C (int16 LE) | MCU 内部温度（°C×100） |

## 0x83 — 电压应答（4 字节）

| 字节 | 字段 | 单位 | 描述 |
|------|------|------|------|
| 0-1 | `vin_mv` | mV (uint16 LE) | 主母线输入电压（1/23 分压） |
| 2-3 | `vin_dcdc_mv` | mV (uint16 LE) | VIN_DC-DC 输入电压（1/23 分压） |

## 0x90 — 控制命令（主机 → 板，负载 1 字节）与 ACK

| 负载字节 | 字段 | 描述 |
|----------|------|------|
| 0 | `buzzer_duty` | 蜂鸣器**导通占空比 0-50%**（0=静音，50=最响；固件对超限值截断到 50） |

板收到后立即应用（蜂鸣器 PWM 直驱，导通占空比上限 50%），应答 `0x90` + payload[0]=`0x00`。

## 0x91 — 升级请求（预留）

负载 1 字节（magic `0x01`）。本阶段固件应答 `0x7F`，payload[0]=`0x02`（不支持）。
将来实现 RS485 固件升级时另行定义升级握手与烧写流程。

## 交互流程示例

| 步骤 | 主机 | 方向 | 板 |
|------|------|------|----|
| 1 | `z 01 00 crc \n`（读状态） | → | |
| 2 | | ← | `z 81 02 [状态2B] crc \n` |
| 3 | `z 10 01 32 crc \n`（蜂鸣器 duty=50） | → | 蜂鸣器响 |
| 4 | | ← | `z 90 01 00 crc \n` ACK |

## 软件映射

- 服务层 `srv_com_mst`：
  - 解析：`protocol_parser`（m_middlewares，header=`'z'`/footer=`'\n'`、长度字段回调、CRC8 校验回调）
  - 打包：`protocol_packer`（同一信封 + `fill_len_cb`/`checksum_cb` 回填 data_len 与 CRC8）
  - 语义：读状态/温度/电压经 `read_data` 回调取数，控制经 `ctrl` 回调应用，应答帧经 `send_frame` 回调上抛
- 驱动层：`drv_uart`（USART3 DMA TX 队列 + RX circular/IDLE→kfifo，参考 G0 drv_uart）；`dev_rs485`（RS485_EN DE/RE 方向控制 + TX 完成自动释放总线）
- 任务层：`com_task` 每 10ms 搬运 dev_rs485 字节 → `srv_com_mst_rx_feed()`（含 `rx_tick` 空闲超时），并周期 `dev_rs485_tx_flush()` 排空
- 应用层：`app_status_report_fill` 聚合 `srv_pwr_det`/`srv_adc`/`srv_fan_ctrl` 填充上报体，注册为 `read_data` 回调

## 未决/待实机确认

1. E_STOP_ON（PC9）极性：当前按低有效（按下=低）实现。
2. 蜂鸣器频率 4kHz、风扇 PWM 25kHz、NTC B=3950/R25=10k 均为默认值。
3. 帧格式/命令码为起草版本，以本文件为准与主机侧联调（与 G0 上位机 z 帧同构，可复用其收发代码）。
